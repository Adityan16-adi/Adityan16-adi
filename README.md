### [Pragti: Learning & Virtual Classroom](https://github.com/Adityan16-adi/brl-final_task-)

**Flutter · Dart · Firebase Auth · Node.js · Express · MongoDB · LiveKit · FastAPI**

A team project that combines Google Classroom-style learning (notes, assignments) with Meet-style live classes in one app. It has student and teacher roles, Firebase sign-in, live meetings through LiveKit, and an AI mentor backed by a FastAPI service.

**My role:** I built and own the Flutter mobile app, including the UI, auth flow, and API integration.
