# Adityan16-adi — GitHub Profile Setup

This folder contains a cyberpunk-style profile README and two GitHub Actions workflows:
- `snake.yml` generates dark/light contribution snake SVGs and publishes them to the `output` branch.
- `profile-3d.yml` generates the 3D contribution calendar in `profile-3d-contrib/`.

## 1. Create/open the special profile repository

Open https://github.com/Adityan16-adi/Adityan16-adi

GitHub displays a profile README when the public repository name exactly matches the account username. If the repository does not exist, create a **public** repository named `Adityan16-adi`. Add a README if GitHub offers that option.

## 2. Copy these files into the repository

Copy the contents of this package into the repository root, keeping the paths exactly:

```text
Adityan16-adi/
├── README.md
└── .github/
    └── workflows/
        ├── snake.yml
        └── profile-3d.yml
```

Commit and push them to the repository's default branch. The workflow uses `main` for its push trigger; if your default branch has a different name, either rename the branch to `main` or edit the trigger in `profile-3d.yml`.

## 3. Allow GitHub Actions to write generated files

In the profile repository:
1. Open **Settings → Actions → General**.
2. Under **Workflow permissions**, choose **Read and write permissions**.
3. Save.

This is needed because the workflows publish generated images. Do not create or paste a personal access token for these workflows; the repository's `GITHUB_TOKEN` is used.

## 4. Run the workflows once

1. Open the repository's **Actions** tab.
2. Select **Generate contribution snake** → **Run workflow**.
3. Select **Generate 3D contribution calendar** → **Run workflow**.
4. Wait for both runs to finish successfully.

The snake workflow creates an `output` branch. The 3D workflow commits its generated images to the default branch.

## 5. Verify the images

After successful runs, these should exist:
- `output` branch: `github-snake.svg` and `github-snake-dark.svg`
- Default branch: `profile-3d-contrib/profile-night-rainbow.svg`

If the README is cached, refresh the profile after the workflows finish. If a workflow fails, open its run and inspect the failed step.

## 6. Update the project links

Only the InsightAgent repository URL was confirmed when this README was prepared. The PRAVEG, Campus Marketplace, and Pokédex cards intentionally do not link to guessed repository paths. Edit `README.md` and add each exact repository URL once you verify it.

The LinkedIn URL was taken from the existing profile draft; verify it before publishing. The Email badge intentionally has no destination until you choose to expose a public email address—replace `href="mailto:"` with your intended email link or remove that badge.
